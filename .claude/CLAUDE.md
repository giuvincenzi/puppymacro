# PuppyMacro

Macros, auto clicker and key remapper for Windows (.NET 10, WPF).

The rules are in `.claude/rules/`, one topic per file:

- `working-rules.md`: how Claude works with the user on this project
- `git-workflow.md`: how every change is made in git and reaches `main`
- `build-and-release.md`: how the app is built, signed and released
- `testing.md`: which tests the project has and when they run
- `docs.md`: how the website, the user guide and the README are written and published
- `discoverability.md`: how people find PuppyMacro on search engines and in MCP registries
- `i18n.md`: how the app and the website are translated
- `architecture.md`: how the app's code is organized
- `input.md`: how PuppyMacro reads and sends keyboard and mouse input
- `data.md`: where user data is saved and how it stays compatible between versions
- `ui.md`: how the app's windows and controls must look
- `updates.md`: how the installed app updates itself

When a rule file is added, removed or renamed, update this list.
