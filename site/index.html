PuppyMacro

Everything you repeat, in one place

Loops

Press a key or mouse button every 10 ms to 24 h, keep it held down, or paste a text. Several rows, each on its own timer.

Macros

Record keys, clicks, scroll and mouse movement, then edit every step, in a list or as code with suggestions and live checks. Play once, N times or in a loop, at ×0.25 to ×4 speed.

Remap

A key or mouse button sends another key, button or combination, in all apps or only in the app you choose.

Overlay mode

A small always-on-top panel over your game or fullscreen app, and round floating buttons you place anywhere, each with its own opacity. Use both or only the buttons. Click them to start or stop without the app losing focus.

Hotkeys

Any key, mouse button or combination with Ctrl, Alt, Shift or Win, also Ctrl+click or Alt+scroll wheel. Toggle or Hold. Stop all, Overlay mode and Record are one shortcut away.

Always up to date

PuppyMacro checks for new versions and updates itself with one click. Your loops, macros and remaps stay.

Install in a minute

  1. 1Download PuppyMacro-win-Setup.exe.
  2. 2Run it. If Windows shows “Windows protected your PC”, select More info, then Run anyway.
  3. 3Done. PuppyMacro starts and is in the Start menu. Setup installs the .NET 10 Desktop Runtime and the WebView2 Runtime if they are missing.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Our application to the SignPath Foundation is being reviewed: until it is approved, releases are not signed and Windows may warn before running Setup.

  • Releases are built by GitHub Actions from the source code in the public repository.
  • Committers and reviewers: Giuseppe Vincenzi
  • Approvers: Giuseppe Vincenzi
  • Uninstall from Windows Settings > Apps > Installed apps.

Privacy

PuppyMacro does not collect or send personal data. With Check for updates automatically (on by default), it contacts GitHub when it starts and every 12 hours to check for and download updates; the GitHub General Privacy Statement applies to those requests. Turn it off in Settings > Updates.
