Everything PuppyMacro keeps (loops, macros, remaps, settings, History, AI activity and logs) is in %AppData%\PuppyMacro, so every new version finds it. In Settings > Backup:

  • Export… asks what to save in one .puppymacro file:
    • Everything (chosen at first): an identical copy. Import it on another PC and you get the same PuppyMacro, with its History and AI activity.
    • Choose what to export: Loops, macros, remaps and settings are always in the file; History, AI activity and Logs can be left out, for a smaller file. Each shows its size.
    Then Export… asks where to save the file.
  • Import… says what the file has and replaces those parts of your data with it, after you confirm with Import and restart. What the file does not have stays as it is: a file without History keeps your History. Your current data is backed up to the data folder first, then PuppyMacro restarts. Files exported by older versions have loops, macros, remaps and settings.
  • Open data folder opens %AppData%\PuppyMacro.

Debug data, under it, is not in backups: the logs and pictures of AI requests and of macros with Debug on, kept 7 days in %LocalAppData%\PuppyMacro\debug. The card says how much space they take; Open folder opens it and Delete all deletes everything except what is in progress.

To share only some loops, macros or remaps, without replacing anything, use Import and Export at the top of the window instead: see Share loops, macros and remaps. A backup file shows an archive box with PuppyMacro's paw in File Explorer; it opens only from here.

If Start with Windows is on in the imported settings, PuppyMacro turns it on in Windows the next time it starts.
