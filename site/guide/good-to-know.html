• If the app you automate runs as administrator, run PuppyMacro as administrator too. Start with Windows cannot start it elevated.
  • Mouse rows and macro clicks never click on PuppyMacro's own windows.
  • The main window keeps its size and position for the next start.
  • While a loop, macro or remap editor is open, the main window hides, and it comes back when the editor closes. The editor has its own button on the taskbar.
  • Settings > About shows the version of PuppyMacro, with links to this User guide, to GitHub and to Support PuppyMacro (a donation of any amount through GitHub Sponsors).
  • Questions or problems: open an issue on GitHub.
