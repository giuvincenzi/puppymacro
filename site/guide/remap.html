Press a key or mouse button and PuppyMacro sends another one instead. Remaps work while PuppyMacro is running, also in the system tray. Select Add remap on the Remap page.

  • When I press: select Set key and press a key or mouse button (Esc cancels). The key is then shown in the accent color: click it to choose another one.
  • Send instead: a key, a mouse button or a combination (hold Ctrl, Alt, Shift or Win first), chosen the same way.
  • Works in: All apps, or A specific app: pick a running app or Browse… for its .exe. The remap works only while that app is in front.
  • Note (optional): a reminder, shown on the remap's card.
  • Left and right click can be remapped only for a specific app.
  • Code view, at the top of the window, shows the remap as JSON, as it is saved, in a code editor with suggestions and checks; see Macros > Code view.

On the Remap page each remap is a card titled with its keys, for example CapsLock → Esc, with its state (Enabled or Disabled), where it works and its note. On the right: Edit (the pencil), the switch that enables or disables it, and More options (⋯) with Duplicate and Delete. A duplicate starts disabled, ready to be changed. Search and the filter (All remaps, Enabled, Disabled) help with long lists.
