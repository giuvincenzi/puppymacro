Share loops, macros and remaps with a friend, or take a few of them to another PC, as one .puppyitems file. Importing one only adds items: it never changes or removes yours. To copy all of PuppyMacro, settings and History too, use the backup instead.

Export

  • Export, at the top of the window, lists your loops, macros and remaps by kind. Check the ones to share: Search and the kind (All kinds, Loops, Macros, Remaps) narrow the list, Select all shown checks what the list shows, and the count says how many are shown and selected. Export 3 items… asks where to save the file.
  • For one item, Export… in its card's More options menu (⋯) saves it at once, named after it.

The file is text (JSON): each item is written as its editor's Code view shows it.

Import

Import, at the top of the window, asks for a .puppyitems file. You can also double-click the file in File Explorer: PuppyMacro opens it, or shows it in the PuppyMacro already running (if an editor or dialog is open, after you close it). The window shows the file's name, the PuppyMacro version that made it and what it has, by kind, each with a check box; Choose another file… opens another one.

  • Every item comes as a new one, disabled: check what it does, then turn it on with its card's switch.
  • A name you already use gets a number: A loop has this name: imported as "Farm (2)".
  • A hotkey already used, by your items or by an item checked above it in the file, is left out, and the item is imported without one: give it another in its editor. An item in Hold mode becomes Toggle, as Hold needs a hotkey.
  • A remap of a key that is already remapped, or used by a hotkey, in the same apps can't be imported: its box is off and says why.
  • An item with a problem (for example a sound this version does not have) can't be imported and says why; the others can.
  • A file made by a newer PuppyMacro, with something this version does not know, asks you to update PuppyMacro first: Check for updates opens Updates.

Import 2 items adds the checked items and shows the page of the first one.

With an AI app

An AI app connected to PuppyMacro can do the same: give you the text of a .puppyitems file with the items you ask for, or import the items of a file you paste in the chat, new and disabled as above. With Ask before changing a loop, macro or remap on, it asks you first. It can also open PuppyMacro's own Import and Export windows, for you to choose there.

File icons

In File Explorer a .puppyitems file shows a page with PuppyMacro's paw, and a .puppymacro backup an archive box with the paw. A backup does not open with a double-click: import it from Settings > Backup, as it replaces your data.
