Select Enable overlay mode or press the Overlay mode hotkey (Alt+Shift+W on a new install). The main window hides and the overlay stays on top of the app you are using, for example a game in windowed fullscreen. The overlay is made of the overlay panel, with the enabled loops and macros, and the floating buttons.

  • The overlay never takes focus from the app below it. With Click items in the panel to start or stop them (Settings > Overlay, on by default), you can click loops and macros in the overlay panel to start or stop them. Hold items stay hotkey only.
  • The overlay is visible only on windowed fullscreen or borderless windows, not on apps in exclusive fullscreen.

Overlay panel

  • Show the overlay panel in Settings > Overlay is on by default. Turn it off to have only the floating buttons in overlay mode; the panel's other settings are off meanwhile. Without the panel, leave overlay mode with the Overlay mode hotkey.
  • Opacity sets the panel's background; the text stays fully visible. Position is where the panel appears, measured from the top-left corner of the main screen; Reset puts it back there.

Floating buttons

A loop or macro can also have its own round button in overlay mode, which you can put anywhere on the screen: next to a game's action bar, in a corner, on another monitor. Click it to start or stop the loop or macro. Like the panel, it never takes focus from the app below, and the click never reaches that app.

AAF6 CH TC
  • Turn it on in the loop or macro editor with Floating button. Label sets the one or two characters in the button (proposed from the name), Size is S, M or L, and Opacity sets the button's background, from 20% to 100%. Each button has its own opacity. The hotkey, if any, is shown on the edge of the button.
  • A running loop or macro has a green ring, like its row in the panel.
  • A loop or macro with a floating button is not listed in the panel, so it is never shown twice. Turn the button off to get its row back.
  • A new button appears in the middle of the main screen until you place it.
  • Floating buttons are always clickable, also when Click items in the panel to start or stop them is off.
  • Hold loops and macros cannot have a floating button: a click can only start and stop.

Position on screen

Position on screen in Settings > Overlay and Position… in the loop or macro editor open the same view of the whole overlay, as overlay mode shows it: the overlay panel (when Show the overlay panel is on) and every floating button. Drag each one where you want it. The last one you clicked is selected and moves with the arrow keys (Shift moves ×10). Press Enter to save or Esc to cancel.
