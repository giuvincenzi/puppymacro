Select Enable overlay mode or press the Overlay mode hotkey (Alt+Shift+W on a new install). The main window hides and the overlay stays on top of the app you are using, for example a game in windowed fullscreen. The overlay is made of the overlay panel, with the enabled loops and macros, and the floating buttons.

  • Press the Overlay mode hotkey again to leave overlay mode. The main window goes back to how it was before: open, minimized, or in the system tray. Selecting the tray icon, or starting PuppyMacro again, leaves overlay mode and opens the window.
  • The overlay never takes focus from the app below it. With Click items in the panel to start or stop them (Settings > Overlay, on by default), the overlay panel is clickable: click a loop or macro to start or stop it (Hold items stay hotkey only), Stop all at the bottom to stop everything, and the exit button at the top right to leave overlay mode.
  • The overlay is visible only on windowed fullscreen or borderless windows, not on apps in exclusive fullscreen.

Overlay panel

  • Show the overlay panel in Settings > Overlay is on by default. Turn it off to have only the floating buttons in overlay mode; the panel's other settings are off meanwhile. Without the panel, leave overlay mode with the Overlay mode hotkey.
  • It lists the enabled loops, then the macros, each with its hotkey and its state (a running one is green). A loop or macro with a Specific app is listed only while that app is in front; when nothing is left for the app in front, the panel says “Nothing for this app.” Stop all, at the bottom, shows its hotkey. When the panel can be clicked, Stop all turns red while something runs; when it cannot, the move and exit buttons are dimmed.
  • Opacity sets the panel's background; the text stays fully visible. Position is where the panel appears, measured from the top-left corner of the main screen (X, Y); Reset puts it back there.
  • To move the panel during overlay mode, press the move button (four arrows, next to the exit button) and drag. The panel follows the mouse and its new position is saved, as with Position. Like the other buttons of the panel, it works only with Click items in the panel to start or stop them on, and the app behind keeps the focus.

Floating buttons

A loop or macro can also have its own round button in overlay mode, which you can put anywhere on the screen: next to a game's action bar, in a corner, on another monitor. Click it to start or stop the loop or macro. Like the panel, it never takes focus from the app below, and the click never reaches that app.

  • Turn it on in the loop or macro editor with Floating button. Label sets the one or two characters in the button (proposed from the name), Size is Small, Medium or Large, and Opacity sets the button's background, from 20% to 100%. Each button has its own opacity. The hotkey, if any, is shown on the edge of the button.
  • A running loop or macro has a green ring, like its row in the panel.
  • A loop or macro with a floating button is not listed in the panel, so it is never shown twice. Turn the button off to get its row back.
  • A new button appears in the middle of the main screen until you place it.
  • The button of a loop or macro with a Specific app is shown only while that app is in front.
  • Floating buttons are always clickable, also when Click items in the panel to start or stop them is off.
  • Hold loops and macros cannot have a floating button: a click can only start and stop.

Position on screen

Position on screen in Settings > Overlay and Position… in the loop or macro editor open the same view of the whole overlay, as overlay mode shows it: the overlay panel (when Show the overlay panel is on) and every floating button, also those for other apps. Drag each one where you want it. The last one you clicked is selected and moves with the arrow keys (Shift moves ×10). Press Enter to save or Esc to cancel.
